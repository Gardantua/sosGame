# X-O konsol oyunu

Python'a başlarken yazdığım, bilgisayara karşı oynanan 3×3 X-O oyunu. Hamleleri, oyun tahtasını ve kazanma durumunu konsolda takip ediyor.

```bash
python sosGame/sosGame.py
```

Python 3 dışında paket gerekmiyor. Repo adı SOS olsa da mevcut kod X/O eşleştirmesiyle çalışan tic-tac-toe oyunudur. İlk dönem öğrenme projem olarak saklıyorum.
